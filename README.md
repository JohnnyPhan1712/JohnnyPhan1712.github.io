# Personal CV Website

CV cá nhân của Phan Ngọc Đức Huy được xây dựng bằng HTML5 và CSS3.

## Nội dung áp dụng

- Cấu trúc HTML5 semantic: `header`, `nav`, `main`, `section`, `article`, `footer`.
- Các thẻ văn bản, liên kết và danh sách cơ bản.
- CSS tách riêng, bố cục responsive cho máy tính và điện thoại.
- Chế độ in để có thể lưu trang thành PDF.

## Chạy dự án

Mở trực tiếp file `index.html` bằng trình duyệt hoặc truy cập GitHub Pages của repository.
